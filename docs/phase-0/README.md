# Phase 0 evidence

Phase 0 was a measurement/spike phase for the `catboostr` fork (design spec:
`docs/superpowers/specs/2026-07-30-catboostr-design.md`). Its evidence
previously lived only under `.superpowers/sdd/phase-0/` and
`.superpowers/sdd/phase-0/...` build logs in a scratch directory, both of
which are gitignored (`.superpowers/` in `.gitignore`) -- so none of it was
part of the committed tree a Phase 1 contributor could inspect. This
directory commits the decisive subset (fix-wave finding C1).

## Files

- `catboost-8z4.1-report.md` -- native core acquisition/build task report.
  Establishes: the vendored-upstream build path (Conan + CMake + Ninja,
  R-package CMake target only), the offline-vs-network-on build comparison,
  and the wall-clock numbers referenced in spec §4.1/§7 (labelled below).
- `catboost-8z4.2-report.md` -- native routine registration task report.
  Establishes: the cpp11/`.Call` registration-collision mechanism and its
  fix, proved by the probe package now committed at
  `tools/probes/cpp11-registration/` (fix-wave finding C2).
- `catboost-8z4.3-report.md` -- offline/zero-network build task report.
  Establishes: what "offline" actually means for this build (pre-populated
  Conan cache + venv with NumPy/Cython, `conan remote disable conancenter`)
  -- NOT a from-scratch no-network-ever install. That distinction is why
  spec §7's "RETIRED" risk entry was reworded (see spec changelog note
  below); it also documents the `.cbm` embedded timestamp/GUID
  non-determinism referenced by the `.gitignore` entries for
  `smoke_model.cbm`.
- `catboost-8z4.4-report.md` -- oracle fixture task report (Python + CLI
  oracles, smoke dataset generation).
- `catboost-8z4.5-report.md` -- capability inventory task report (Python
  surface introspection, CLI surface enumeration, capability diff, spec
  cross-check). The generating tools now live under `tools/parity/`, see
  `tools/parity/README.md`.
- `ledger.md` (renamed from `progress.md`) -- the Phase 0 task-by-task
  ledger: what ran, in what order, and its outcome.
- `run1_network_on.trimmed.log` -- decisive lines (configure invocation,
  Conan bootstrap header, final ~60 Ninja lines, exit status/timing) trimmed
  from the untracked 2,268,651-byte / 10,108-line network-ON build log
  referenced by `catboost-8z4.3-report.md`. `elapsed_seconds=164`. This is
  the **network-ON** reference build (spec §4.1/§7's "164 s" figure).
- `run6_offline_final.trimmed.log` -- decisive lines trimmed from the
  untracked 860,362-byte / 7,868-line offline build log, same shape as
  above. `build_seconds=172 total_seconds=174`. This is the **offline,
  given pre-populated Conan cache + venv** reference build (spec §4.1/§7's
  "174 s" figure) -- not a clean-machine/no-network-ever install.

Both trimmed logs state in-file what was cut and why (per-target Ninja
progress lines only; no decisive content removed).

## Non-evidence decisions recorded here

- `tests/fixtures/oracle/smoke_model.cbm` and
  `tests/fixtures/oracle-cli/smoke_model.cbm` are **not** committed (see
  `.gitignore`): CatBoost embeds a training-run timestamp/GUID in `.cbm`
  files, so a byte-identical fit still produces a different file every run
  (predictions are bit-identical; only container metadata varies -- see
  `catboost-8z4.3-report.md` and `catboost-8z4.4-report.md`). They are
  regenerated by `tools/oracle/gen_smoke_fixture.py` and
  `tools/oracle/cli/gen_smoke_fixture.sh` instead of tracked.
