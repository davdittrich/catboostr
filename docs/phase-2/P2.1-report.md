# P2.1: Build parity matrix join tool — report

Ticket: `catboost-8z4.34`. Worktree: `/home/dd/Gemini/catboost-phase2` (branch
`phase-2-parity-matrix`).

## What was built

`tools/parity/build_matrix.py` — reads `tests/fixtures/parity/capability_diff.json`
(1537 raw `gaps` rows), merges rows sharing a `dedup_key` into one row per
key (363 groups) and passes through the 362 rows with no `dedup_key`
unchanged, and writes `tests/fixtures/parity/matrix.json` (725 rows).

Per row: `inventory_row_id`, `oracle`, `kind`, `method`, `tolerance`,
`test_id`, `state`, `tolerance_justification`, `needs_disposition`,
`members`, `universal` — exactly the schema in ticket §IV step 8, no
extra/omitted fields (verified below).

Method assignment (ticket §IV step 5, in priority order):
1. `universal: true` → `method: non_capability` (regardless of kind).
2. `kind in (parameter, flag)` and not universal → `method: parameter_or_flag`.
3. `kind == enum_member` → `method: enum_member`.
4. capability name contains `plot_tree` or `calc_feature_statistics`
   (case-insensitive, the two structural examples spec §4.3 names
   explicitly) → `method: structural`.
5. Everything else → `method: null`, `needs_disposition: true` (P2.3's job).

`tolerance` is `null` / `tolerance_justification` is `""` for every row in
the current data: no row is assigned `elementwise` (the only method with a
non-`n/a` numeric default), since the only method this ticket ever assigns
besides the null/placeholder categories is `structural`, which the spec's
verification-method table marks `n/a`. The precision-ceiling
(`validate_precision_ceiling`, CLI tolerance floor `1e-9`) and
tolerance-justification (`validate_tolerance_justification`, non-default
tolerance without a justification string) checks are enforced as functions
called on every row during construction (`build_row`), raising `ValueError`
on violation — not just documented. They are exercised with synthetic bad
input in `tools/parity/test_build_matrix.py` since no row in the real fixture
currently has a non-null tolerance to trigger them organically.
