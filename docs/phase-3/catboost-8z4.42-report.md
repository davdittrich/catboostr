## Review of existing diff

- `catboost.FeaturesData()` (R/catboost.R): S3 list container with fields
  `num_feature_data`, `cat_feature_data`, `num_feature_names`,
  `cat_feature_names` — matches the Python oracle's field contract
  (`_catboost.pyx:2206`: `num_feature_data`, `cat_feature_data`,
  `num_feature_names`, `cat_feature_names`; no embedding field). Validates
  at-least-one-part-non-NULL, matrix/type/row-count/name-length invariants.
- 5 accessors present: `get_object_count`, `get_num_feature_count`,
  `get_cat_feature_count`, `get_feature_count`, `get_feature_names`.
- Wiring: `catboost.load_pool` dispatches `inherits(data, "catboost.FeaturesData")`
  before the `data.frame` branch, rejects `cat_features`/`feature_names`
  passed alongside it, and forwards to `catboost.from_matrix`.
  `catboost.from_matrix` detects a `FeaturesData` first argument, hashes the
  categorical matrix via the existing `CatBoostHashStrings_R` (same call used
  by `catboost.from_data_frame` for factor columns), `cbind`s num+cat into one
  matrix, and derives `cat_features_indices` as the zero-based
  `seq.int(num_ncol, num_ncol + cat_ncol - 1)` range — correct because cat
  columns are always appended after the num columns in the combined matrix,
  and `cat_features_indices` elsewhere in this file is documented/used as
  zero-based (see `catboost.from_data_frame`'s `column_index - 1`).
- Found and fixed one bug in the diff-under-review: `man/catboost.caret.Rd`
  drops `\docType{data}`/`\format{}` — confirmed as a benign roxygen2 8.0.0
  regen side effect (this repo's roxygen2 no longer infers those tags for a
  bare-list `@export` without an explicit `@format` tag), not a bad hand
  edit — left as-is, no `R/catboost.caret.R` tag changes needed.
- Found and fixed a bug in `tests/testthat/test_features_data.R`: the
  "wired into `catboost.from_matrix`" test called the internal (non-exported)
  `catboost.from_matrix` unqualified, which fails under `library(catboostr)`
  since only `catboost.load_pool`/`catboost.from_data_frame` etc. are
  exported. Fixed to `catboostr:::catboost.from_matrix(...)`, matching the
  existing internal-function-access convention in
  `tests/testthat/test_version_skew.R` (`catboostr:::.catboost.check_version_skew`).

No other correctness or completeness gaps found; no C++ changes were needed
(pure R diff), so no rebuild was performed per the ticket's constraint.
